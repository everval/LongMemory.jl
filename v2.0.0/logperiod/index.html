Semiparametric Estimators for Long Memory

Functions to estimate the long memory parameter based on the log-periodogram regression. Estimators include the Geweke and Porter-Hudak estimators and the Whittle estimator.

LongMemory.LogPeriodEstimators — Module

LogPeriodEstimators

This module contains functions to estimate the long memory parameter of a time series using the log-periodogram estimator and the Whittle log-likelihood function.

Author

J. Eduardo Vera-Valdés

LongMemory.LogPeriodEstimators.exact_whittle_est — Method
exact_whittle_est(x::AbstractArray; m::Real=0.8, l=0, demean::Bool = true)

Estimate the long memory parameter of a time series x using the exact Whittle log-likelihood function. See Shimotsu and Phillips (2005) for details.

Arguments

  • x::Vector: time series
  • m∈(0,1)::Float64: taper final
  • l∈(0,1)::Float64: taper initial
  • demean::Bool: If true, the time series is demeaned with the sample mean before estimation.

Output

  • d::Float64: long memory parameter

Notes

The function considers the periodogram of the time series x at the Fourier frequencies 2πj/T for j in [T^l,T^m] (rounded). The zero frequency is always excluded, so round(T^m) frequencies are used when l = 0. The condition l < m must hold. The default values of m and l are 0.8 and 0, respectively. The sample mean is a poor estimator of the mean when d > 1/2; see feasible_exact_whittle_est for a version that is robust to an unknown mean.

Examples

julia> exact_whittle_est(randn(100,1))

exact_whittle_est_variance(x::AbstractArray; m::Real=0.8)

Estimate the variance of the estimator for the long memory parameter of a time series x using the exact Whittle log-likelihood function.

Arguments

  • x::Vector: time series

Optional arguments

  • m∈(0,1)::Float64: taper final. Default is 0.8

Output

  • varb::Float64: variance of the estimator

Notes

Multiple dispatch is used for computation. If the first input is an integer, the function interprets it as the sample size; otherwise, it computes the sample size from the length of the time series. The variance is the same as the one from using the Whittle log-likelihood function.

LongMemory.LogPeriodEstimators.feasible_exact_whittle_est — Method
feasible_exact_whittle_est(x::AbstractArray; m::Real=0.8, l=0)

Estimate the long memory parameter of a time series x with unknown mean using the feasible exact local Whittle estimator of Shimotsu (2010).

Arguments

  • x::Vector: time series
  • m∈(0,1)::Float64: taper final
  • l∈(0,1)::Float64: taper initial

Output

  • d::Float64: long memory parameter

Notes

The exact Whittle objective is evaluated on x - μ(d), where the mean estimate depends on d: μ(d) = w(d) x̄ + (1 - w(d)) x₁, with w(d) = 1 for d ≤ 1/2, w(d) = (1 + cos(4πd))/2 for 1/2 < d < 3/4, and w(d) = 0 for d ≥ 3/4. The sample mean is a good estimator of the mean for d < 1/2, while the first observation is a better one for d > 1/2. The objective is minimized over d∈[-1/2, 2] with Brent's method. The asymptotic variance is 1/(4m), the same as for the (exact) Whittle estimator, see exact_whittle_est_variance. The function considers the periodogram at the Fourier frequencies 2πj/T for j in [T^l,T^m] (rounded), excluding the zero frequency.

Examples

julia> feasible_exact_whittle_est(5 .+ fi_gen(500, 0.8))

LongMemory.LogPeriodEstimators.gph_est — Method
gph_est(x::AbstractArray; m::Real=0.8, l=0, br=0::Int)

Estimate the long memory parameter of a time series x using the log-periodogram estimator. See Geweke and Porter-Hudak (1983) and Andrews and Guggenberger (2003) for details.

Arguments

  • x::Vector: time series
  • m∈(0,1)::Float64: taper final
  • l∈(0,1)::Float64: taper initial
  • br::Int64: number of bias reduction terms

Output

  • d::Float64: long memory parameter

Notes

The function considers the periodogram of the time series x at the Fourier frequencies 2πj/T for j in [T^l,T^m] (rounded). The zero frequency is always excluded, so round(T^m) frequencies are used when l = 0. The default values of m and l are 0.8 and 0, respectively. The condition l < m must hold.

The default value of br is 0 which returns the original GPH log-periodogram estimator.

Examples

julia> gph_est(randn(100,1))
